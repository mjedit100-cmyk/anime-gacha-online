## Get playing (Windows)

1. Open the **[latest release](https://github.com/mjedit100-cmyk/anime-gacha-online/releases/latest)**
2. Download **Just-MJ-Games-Setup-….exe**
3. Install, then launch from desktop / Start Menu
4. First boot checks for updates, then you pick a game

Already installed? Launch **Just MJ Games** with Wi‑Fi — it updates before you play.

## Windows warning? Don’t panic

If SmartScreen or antivirus says the installer is unrecognized, **that does not mean this is a virus**. New indie apps without a paid publisher certificate get that warning.

1. Click **More info**
2. Click **Run anyway**
3. Finish install and play

Only download Setup from **this official page**.

## Updates & saves

The desktop client checks this Releases page for the Setup package. Your save lives on your PC across patches (updates never wipe). Uninstall is the only time Windows asks **Keep** or **Wipe**.

Player notes live on the [studio site](https://mjedit100-cmyk.github.io/anime-gacha-online/updates.html) — fights, menus, gifts, and login. Not studio plumbing.
